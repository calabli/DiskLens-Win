速度

一百多万个文件，
半分钟看完。

以管理员身份运行时，DiskLens 直接读取 NTFS 的主文件表，不用一个个打开文件夹。扫描结果会保存下来，下次打开只读取这之后的变化。

28.5秒

扫完一块装有 163 万个文件的 200 GB 数据盘。这还是没有管理员权限时的普通遍历。

MFT

以管理员身份扫描整块 NTFS 磁盘时，直接读主文件表，不受文件夹权限限制。

USN

再次打开或切回窗口时，按 USN 日志只更新变过的文件，不必重扫。

2.1MB

整个安装包的大小。界面用系统自带的 WebView2，不另带浏览器。

边扫边看

扫描还没结束，最大的几个文件夹就已经排在眼前，越扫越准。

算的是真实占用

按磁盘上实际分配的空间统计，压缩和稀疏文件都算得准。逻辑大小和占用空间分开显示。

读不到的也告诉你

没有权限打开的文件夹单独列出原因，一键以管理员身份重新扫描。

方块图与旭日图

空间去哪了，
颜色先告诉你。

方块越大，占得越多。七种颜色对应七类文件，相邻的方块一定深浅不同，挤在一起也分得开。换成旭日图，文件夹一圈圈往外展开，层级关系一目了然。

    • 方块里再套方块一次显示一到三层，不用点进去也能看到大文件夹里装的是什么。
    • 列表和图联动选中、放大、返回，左边的列表和右边的图一起动。Ctrl 点按可以多选。
    • 中键直接打开在任何一行或一个方块上按鼠标中键，资源管理器就停在那个位置。

    搜索

    几百万个文件里，
    打几个字就找到。

    在整次扫描里搜索文件和文件夹，按大小从大到小排好。搜索时，没命中的方块变成灰色，要找的东西在哪儿一眼就能看到。

    size:>1gb大于 1 GB 的文件和文件夹
    ext:iso;zip扩展名是其中之一
    type:音视频按类别，七类都可以
    dm:>7d最近 7 天内修改过
    da:<1y一年以上没打开过
    folder: 只要文件夹；换成 file: 只要文件
    !backup名称里不含 backup
    "program files"带空格的名称用引号括起来

    清理建议

    不只告诉你能删什么，
    还告诉你删了会怎样。

    二十多条内置规则，覆盖浏览器缓存、系统临时文件、Windows 更新缓存，以及 node_modules、Rust、.NET、Gradle、Maven 这些开发产物。每一条都写明后果，只有低风险的会默认勾选。

    可以释放 19.4 GB其中 14.8 GB 是可以放心清理的缓存（示例数据）

    Chrome 缓存 低风险

    3.2 GB

    删除后：网页第一次打开会稍慢，登录状态、书签和历史记录不受影响。建议先关闭 Chrome。

    Windows 更新下载缓存 低风险

    2.6 GB

    删除后：如果有更新正在下载或等待安装，可能需要重新下载。

    node_modules 低风险

    9.0 GB

    删除后：再次运行项目前需要执行 npm install（或 pnpm / yarn install）重新安装。

    旧系统备份（Windows.old） 中风险

    4.6 GB

    删除后：无法回退到以前的 Windows 版本。

    休眠文件 高风险

    6.4 GB

    删除后：关闭休眠后无法使用休眠和“快速启动”。这一项只给出操作方法，不会替你删除。

    先进回收站

    默认移到回收站，随时可以恢复。每次删除都会写进日志，记下删了什么、从哪里删的。

    系统位置不让删

    Windows、Program Files 这些关键位置受保护，误选了也会被拦下来并说明原因。

    正在用的会跳过

    被程序占用的文件不硬删，跳过并告诉你是哪几个。

    在列表、方块图、重复文件、排行里看到的东西，右键或拖一下就进收集篮，挑好了一次删除。

    还有更多

    每一个角落，
    都替你看过。

    重复文件

    按大小和内容逐级比对，确认完全相同才算重复。可以只留一份，其余换成硬链接：文件都还在原处，空间只占一份。

    相似图片

    按画面内容找出长得像的照片，缩放过、压缩过的副本也找得到，并排比较后再决定留哪张。

    空文件夹与失效链接

    空文件夹、空文件，以及指向已经不存在位置的快捷方式和链接，逐个核实后列出来。

    大文件与排行

    最大的文件和很久没打开过的文件，标出修改和访问时间。一年没碰过的大家伙一眼可见。

    移到其他磁盘

    把大文件夹搬到另一块磁盘，原位置留下连接点，程序照常找得到它。复制并核对无误后才删除原文件夹。

    存储详情

    页面文件、休眠文件、还原点、WinSxS、更新缓存分项列出，写明是什么、怎样减小，哪些不要碰。

    你的磁盘，
    只有你看得到。

    扫描、分析、清理全部在你的电脑上完成。DiskLens 不联网，不上传文件名，不收集使用数据，也不需要账号。扫描结果和删除日志都存在本机，随时可以删掉。

    技术规格

    系统要求
    Windows 10 或 Windows 11，64 位（x64）
    运行环境
    Microsoft Edge WebView2。Windows 11 已自带；缺少时安装程序会自动下载安装。
    文件系统
    NTFS 支持 MFT 直读和 USN 增量刷新；FAT32、exFAT 和网络位置使用普通遍历。
    权限
    普通用户即可使用。以管理员身份运行时启用 MFT 直读，并能读取系统和其他用户的文件夹。
    安装包
    安装程序（.exe）约 2.1 MB，另有 MSI 版本，方便统一部署。
    界面
    简体中文。浅色、深色，或跟随系统。
    删除方式
    默认移到回收站；也可以彻底删除。每次操作写入本机日志。
